# Academ Print Calculator

MVP внутреннего калькулятора типовых полиграфических заказов для «Академ-принт».
Рассчитывает визитки, листовки, брошюры и широкоформатную печать, показывает
пооперационную калькуляцию, наценку, НДС и цену за единицу.

> Тарифы в `src/printcalc/rates.json` перенесены из публичного прайса как демонстрационные.
> Перед коммерческим использованием их необходимо сверить с типографией.

## Запуск

Требуются Python 3.12 или 3.13 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync --locked --all-groups
uv run uvicorn printcalc.app:app --reload
```

Откройте <http://127.0.0.1:8000>.

## Проверка

```bash
./scripts/check.sh
```

Единый quality gate запускает:

- Ruff lint;
- Ruff format check;
- mypy в строгом режиме;
- Bandit;
- pytest с branch coverage не ниже 60%;
- pip-audit для известных уязвимостей зависимостей.

Этот же gate выполняется в GitHub Actions для каждого push и pull request.

## Архитектура

- `calculator.py` — чистое расчётное ядро без HTTP;
- `rates.json` — версионированные тарифы и производственные ограничения;
- `app.py` — FastAPI и серверный HTML-интерфейс;
- `tests/` — доменные и HTTP-тесты.

## Ограничения MVP

- нет авторизации и ролей;
- нет базы заказов и CRM;
- нет складского или производственного учёта;
- расчёт является предварительным и требует подтверждения менеджером.
